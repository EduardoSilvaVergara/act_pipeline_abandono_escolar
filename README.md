# Data Pipeline - Ingesta de Datos

## 📌 Objetivo
Este proyecto implementa un proceso de ingesta de datos desde un archivo CSV, realizando transformaciones básicas y almacenando los datos procesados como parte de un pipeline de datos.

## ⚙️ Funcionalidades
- Lectura de datos desde CSV
- Limpieza básica (normalización de columnas, eliminación de duplicados)
- Agregado de timestamp
- Logging del proceso (inicio, éxito/error, cantidad de registros)
- Automatización programable
